# 3つだけTODO

1日にやることを **最大3件** に絞って管理する、シンプルなTODOアプリです。

「やることが多すぎて、何から手をつけていいか分からない」を防ぐために、
1日に登録できるTODOを3件までにしています。

## 公開URL

https://sakamo.github.io/three-todo/

## 主な機能

### TODOの管理

- TODOは最大3件まで追加できます（1件あたり50文字まで）
- 3件を超えて追加しようとすると、メッセージが表示されます
- チェックボックスで完了にできます（完了したTODOには取り消し線が付きます）
- TODOを削除できます
- 今日の日付と曜日が表示されます
- 登録件数（例：`1 / 3`）が表示されます

### 今日の達成状況

- 「今日の達成状況：2 / 3件完了」のように、完了した件数が分かります
- 3件すべて完了すると「🎉 今日も完了！」と表示されます

### データの保存

- TODOはブラウザの **localStorage** に保存されるので、ページを再読み込みしても消えません
- 日付が変わると、新しい1日として TODO が空の状態から始まります

### 達成履歴

3件すべて完了した日を「達成した日」として記録し、次の内容を表示します。

- 達成日数
- 連続達成日数
- 直近7日間の達成数（例：`3 / 7日達成`）
- 直近7日間の達成率（%）
- 達成率のプログレスバー
- 直近7日間の日ごとの達成状況（○ / ×、曜日付き。今日だけ強調表示）
- 達成状況に応じたメッセージ
  - 7日達成：「7日間コンプリート！🎉」
  - 5〜6日達成：「かなり順調です！」
  - 3〜4日達成：「いいペースです！」
  - 0〜2日達成：「まずは1日ずつ積み上げよう」
- 達成した日の一覧（新しい日付が上）

## 使用技術

| 技術 | 使いどころ |
| --- | --- |
| HTML | 画面の骨組み（`index.html`） |
| CSS | 見た目の装飾（`style.css`） |
| JavaScript | アプリの動き・データの管理（`script.js`） |
| localStorage | TODOと達成履歴のブラウザへの保存 |
| Git / GitHub | ソースコードのバージョン管理 |
| GitHub Pages | アプリの公開 |
| Claude Code | AIと一緒にコードを書き進める開発ツール |

## ファイル構成

```
three-todo/
├── index.html   # 画面の構造
├── style.css    # 見た目
├── script.js    # 動き（TODOの追加・保存・履歴の計算など）
└── README.md    # このファイル
```

## 使い方

1. 入力欄にやることを入力して「追加」を押します
2. やり終えたらチェックを付けます
3. 3件すべて完了すると、その日が「達成」として履歴に記録されます

ローカルで動かす場合は、`index.html` をブラウザで開くだけで使えます。

## 保存しているデータ

ブラウザの localStorage に、次の3つを保存しています。

| キー | 内容 |
| --- | --- |
| `todos` | 今日のTODO一覧 |
| `todosDate` | TODOを保存した日付（日付が変わったかの判定に使用） |
| `history` | 3件完了した日の記録 |

## 学習目的

このアプリは、**Claude Code を使ったバイブコーディングを基礎から学ぶ**ために作成しています。
小さな機能を1つずつ追加しながら、HTML・CSS・JavaScript や Git / GitHub の使い方を身につけることを目指しています。
